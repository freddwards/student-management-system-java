# Student Management System API (Spring Boot, Java)

## Overview
A Java Spring Boot REST API for managing students, modules, registrations, and grades.  
Originally built for a university assignment and then cleaned up and published as a portfolio project.

## Features
- Manage Students and Modules
- Create Registrations (student to module)
- Store and retrieve Grades
- REST controllers + layered structure (entities, repositories, config, exceptions)
- Automated tests (JUnit)

## Tech Stack
- Java
- Spring Boot
- Spring Web (REST)
- Spring Data JPA
- Maven
- JUnit
